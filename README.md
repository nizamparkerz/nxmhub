## 🛠 Deployed Infrastructure

### 1. Aegis SOS (Core Android Utility)
* **Version:** v1.0.0
* **Deployment Vector:** [Download APK via MediaFire](https://www.mediafire.com/file/ung9bsd7mwztcmu/Aegis+SOS_1.0.apk/file)
* **Architecture:** Flutter / Dart (Native ARM Binaries)
* **Overview:** A high-contrast, tactical safety ecosystem engineered for emergency survival scenarios. Moving far beyond baseline torch scripts, it uses hardware-driven modulation arrays to deploy synchronized warning sounds, multi-frequency hazard flash sequences, custom strobe frequency configuration inputs ($0.1\text{ Hz} - 10.0\text{ Hz}$ variables), and isolated real-time battery cell telemetry tracking.

### 2. Grade to Percentage Converter (Web Engine)
* **Version:** Production Live Build
* **Deployment Vector:** [Launch Conversion Hub](https://gradetopercentage.netlify.app/)
* **Architecture:** Lightweight Static Web Framework
* **Overview:** A fast mathematical parsing tool optimized to process raw academic metrics. It executes instantaneous conversion formulas to translate local state board metrics (SSLC / Plus Two) into precise standalone percentages without tracking cookies or remote script bloat.
